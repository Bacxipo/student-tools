# Contributing

1. Fork the repository and clone your fork.
2. Add the original repository as `upstream`.
3. Create a branch from `main`: `feature/...`, `fix/...`, `docs/...`, `test/...`.
4. Commit with clear messages (`feat:`, `fix:`, `docs:`, `test:`).
5. Run `python -m pytest` before pushing.
6. Open a Pull Request that contains `Closes #<issue-number>`.
7. Wait for at least one review and address all comments.
